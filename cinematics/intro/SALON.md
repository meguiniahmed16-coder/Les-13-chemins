# Actual V27 salon footage

These scripts produce the salon segment for the introduction television film. They use the current, repository-owned room from `membres/v27/scene.js` and `assets/depart-duo/scene.bin`.

`prepare-salon.mjs` executes the original source block that constructs the static interior. It exports the original 11 packed room meshes, original fitted wall and ceiling, and both original backpack instances: 15 objects, 67,744 vertices and 85,809 triangles. Positions, normals, vertex colors, UV coordinates, original textures and object transformations come from that code. The floor texture is generated by the unchanged deterministic source function. No room furniture or architecture is redrawn, generated, substituted or inferred from reference images. The visitor characters and interface are intentionally outside this static interior shot.

`render-salon.py` moves a camera through those meshes using Blender's CPU Cycles renderer. Its material translation retains the exported colors, base-color maps, floor occlusion map, opacity and roughness. The direct lighting uses the original sun/fill directions and colors; a constant material ambient contribution approximates the browser's hemisphere lighting. This is an offline rendering of the actual project geometry, not a pixel-identical browser gameplay recording. The artificial floor contact-shadow sprites are omitted because the offline renderer supplies actual mesh shadows.

## Reproduce

Run these commands from the repository root. Use a temporary output directory outside the repository; textures, exported geometry and frame images are intermediates and should not be committed.

Requirements: project Node dependencies (`three` includes `fflate`), Blender 4.3 with its bundled Python/numpy, and FFmpeg with H.264 support. No browser, Python Pillow package, model generation, external artwork or network access is used.

```sh
npm ci
node cinematics/intro/prepare-salon.mjs /tmp/les13-salon-film
blender -b --threads 8 --python cinematics/intro/render-salon.py -- /tmp/les13-salon-film
ffmpeg -framerate 20 -i /tmp/les13-salon-film/frames/%04d.png -vf hqdn3d=6:6:8:8 -c:v libx264 -preset slow -crf 24 -pix_fmt yuv420p -movflags +faststart -an /tmp/les13-salon-film/salon-v27-8s.mp4
ffmpeg -i /tmp/les13-salon-film/salon-v27-8s.mp4 -frames:v 1 -quality 86 /tmp/les13-salon-film/salon-v27-poster.webp
```

Add `--preview` after the output directory in the Blender command to render only the first and last frames. The default shot lasts 8 seconds at 20 frames per second, 800 × 450 pixels. `--seconds`, `--fps` and `--samples` are optional overrides. The camera uses an eased, continuous lateral dolly from `(1.50, 1.52, 2.20)` to `(0.40, 1.55, 2.08)` in the salon's original coordinate system, looking toward the sofa and upholstered chair. Geometry stays static and unchanged.

The exporter writes `provenance.json` with SHA-256 digests of the scene source and packed geometry archive. Keep that small record with the final montage's source information. The separate salon clip is a build intermediate; the public deliverable is the combined salon-and-board reel.
