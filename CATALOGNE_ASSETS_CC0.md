# Ressources libres — Grand parc de Catalogne (niveau 3)

Le nouveau jeu utilise deux petites ressources **réellement incorporées** dans `catalogne-park-v2.js` sous forme d'images PNG encodées. Leur provenance et leur licence ont été vérifiées avant intégration.

## 1. Kenney — Tiny Town (éléments de nature / texture végétale)
- Source originale : https://kenney.nl/assets/tiny-town
- Source technique de la feuille PNG : https://github.com/GeorgeQLe/assets-2d-city/blob/main/assets/kenney/tiny-town/Tilemap/tilemap.png
- Œuvre publiée par Kenney, **CC0 1.0 Universal** : https://creativecommons.org/publicdomain/zero/1.0/
- Usage : petites touches de feuillage dans les couronnes des arbres du parc.

## 2. Pixel-Boy & AAA — Ninja Adventure
- Source originale : https://pixel-boy.itch.io/ninja-adventure-asset-pack
- Feuille de personnage (version de projet) : https://github.com/pixel-boy/NinjaAdventure/blob/main/content/character/samurai_green/samurai_green.png
- Licence : **CC0 1.0 Universal**, usage personnel et commercial sans attribution obligatoire.
- Usage : figurants ponctuels / artistes de rue dans le parc. Les personnages principaux, les clients et les policiers sont des dessins originaux contemporains adaptés au récit.

Les autres arbres, kiosques, allées, bancs, passants, personnages et animations ont été dessinés spécialement en 2D pour ce mini-jeu. Il n'existe aucun fichier d'asset tiers soumis à une interdiction de redistribution dans cette version.

L'intégration d'une image CC0 n'entraîne aucune concession de droits sur les textes de l'auteur, le récit, les musiques ou le code du jeu.
